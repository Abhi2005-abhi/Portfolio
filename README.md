## 🛠️ Core Tech Stack
- **Frontend Framework:** React 19, Vite
- **Styling & UI:** Tailwind CSS, Glassmorphism design system
- **3D Interactive Engine:** Three.js, React Three Fiber (R3F), Drei (@react-three/fiber)
- **Animations:** Framer Motion (Spring mechanics, orchestrated variants)
- **Tooling:** React Icons, React Scroll, React Helmet Async

## 🚀 Setup & Local Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abhi2005-abhi/Portfolio.git
   ```
2. **Install all dependencies:**
   ```bash
   cd Portfolio
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```

## 🧠 AI Chatbot Feature
This portfolio contains a distinct bottom-right floating AI virtual assistant widget that is pre-programmed to respond dynamically to queries such as "Tell me about your skills", "What are your achievements?", and "Summary", fetching data linearly from the centralized content store.
